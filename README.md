# Blue Jacket — Protótipo Visual

Protótipo estático e navegável, criado apenas para demonstrar a nova direção visual do Blue Jacket. Todos os números, gráficos e listagens são fictícios; nenhuma regra de negócio, consulta de dados, exportação ou persistência foi implementada.

## Áreas incluídas

- Sell Out: Resumo, Redes e Gerencial
- Estoque: Visão Geral, Produtos, Lançamentos e Entradas e Saídas
- Atividades: Criação de Combo
- Clientes e Sortimento: Visão Geral, Sortimento, Lançamentos e Promoções
- Documentos
- Administração: Bases, Cadastros, Metas, Competências, Auditoria, Dados Canônicos e Sincronização
- PEX, com sua tela de estrutura visual

Para abrir localmente, abra `dist/index.html` em um navegador. O protótipo não tem dependências, processo de instalação ou servidor obrigatório.
